# MiniMart

MiniMart is a modern e-commerce frontend application.

## Technologies Used

- React
- Vite
- Tailwind CSS
- Docker
- Nginx
- Git
- GitHub
- GitHub Actions

## Project Structure

- `frontend/` - MiniMart React application
- `compose.yaml` - Docker Compose configuration
- `.github/` - GitHub Actions workflows

## Run with Docker

```bash
docker compose up -d --build

```

## Application Access

Open the application using:

http://YOUR-EC2-PUBLIC-IP:8080

## CI/CD

This project uses GitHub Actions for Continuous Integration.
